Assign a class code

Pick the department, course, intake month and the year the class joined, then type the class code. Format: COURSE-YEAR+INTAKE-SUFFIX, for example EETL6-26S-RS means Electrical Engineering Technology Level 6, September 2026 intake. When you pick a course, the start of the code is filled in for you; finish it with your own ending. The system keeps every code you save. Students choose their department, course and intake when they register and are placed in the matching class automatically. Students who registered before the code existed are moved into it when you save.

A course can have several classes in the same intake (for example EETL6-26S-RS and EETL6-26S-RS2). Add each one.

Courses on the attachment letter

Courses are grouped by department. Choose a department or type a course name to see its courses. The letter text, layout, signature and stamp stay exactly as they are; only the course title, the percentage covered and the list of units change. A course with no units yet shows as "coming soon" to students until units are added (by you, or approved from an ILO representative).

Letter stamps (three semesters)

The stamps carry a year, so upload new ones every year. Add each stamp with the month and year printed on it. The letter picks the right one from the period the student selects: January to April 2027 uses the October 2026 stamp, May to August 2027 the February 2027 stamp, September to December 2027 the June 2027 stamp. PNG or JPG, up to 2 MB. If the stamp for a period is missing, the old signature image is used.

NITA form

Upload the NITA forms every year, one for each stamp (same month and year as the letter stamp). The student gets the form matching the period they select. PDF, Word or image, up to 4 MB each. The single form below is used only when a period's own form is missing.

Units sent by ILO representatives

Check each submission. For units, Approve puts the units and percentage on that course's letter. For an insurance policy, Approve applies it to every student of that class. Reject deletes the submission.
